# Changelog

## v1.1.0

### 🚀 Ядро и архитектура
* **Обновление dnsproxy:** переход на актуальную ветку AdGuard `dnsproxy` (v0.76.0+) с автоматической проверкой свежих релизов при установке.
* **Исправление архитектур:** корректная поддержка `arm64`, `arm` (32-bit), `x86` и `x64` без ошибок скачивания.

### 🛡️ Безопасность и стабильность
* **Fail-Safe запуск iptables:** правила перенаправления трафика активируются только после успешной проверки ответа локального резолвера (`127.0.0.1:5353`). Больше никакого «интернета без DNS» при ошибках апстрима.
* **Полная поддержка IPv6:** добавлены правила `ip6tables` и прослушивание `::1`, что устраняет утечки DNS-запросов (DNS Leaks) в сотовых сетях с IPv6.
* **Чистка от дублей:** умная очистка старых правил `iptables` перед стартом и при остановке службы.
* **Корректный PID-менеджмент:** надежная остановка и перезапуск процессов демона.

### ⚙️ Конфигурация и управление
* **Динамический reload:** настройки из `/sdcard/Download/MyDoH_Config.txt` теперь подтягиваются на лету — переустанавливать модуль больше не нужно!
* **Обход блокировок ТСПУ:** добавлена опция `USE_HTTP3=0/1` для отключения QUIC (UDP/443), предотвращающая зависания DNS-запросов на заблокированных провайдерах.
* **Кнопка Action как тумблер:** нажатие на кнопку действия в Magisk / KernelSU / APatch теперь переключает службу (ВКЛ / ВЫКЛ) или обновляет конфиг.

### 📦 CI/CD и сборка
* Полный переход на GitHub Actions (`actions/checkout@v4`, `softprops/action-gh-release@v2`).
* Добавлена поддержка вечной ссылки `magisk_dns_crypt.zip` для бесшовного автообновления через `update.json`.
