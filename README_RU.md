# Magisk DNS Crypt 🛡️

Magisk / KernelSU / APatch модуль для шифрования DNS-трафика через **dnsproxy** (DoH). 
Весь системный DNS-трафик устройства прозрачно перенаправляется через `iptables` на локальный защищённый резолвер (`127.0.0.1:5353`).

---

### ✨ Особенности
* **Защита от спуфинга и перехвата DNS:** весь трафик с 53 порта (UDP/TCP) заворачивается в DoH.
* **Безопасный старт:** правила `iptables` применяются только после успешной проверки работоспособности резолвера (интернет не пропадёт при ошибках).
* **Гибкая настройка:** поддержка серверов Cloudflare, Google, Comss или любого своего DoH.
* **Совместимость с ТСПУ:** возможность отключения HTTP/3 (QUIC) для предотвращения таймаутов на заблокированных сетях.

---

### 📦 Установка
1. Скачайте актуальный ZIP-архив из раздела **[Releases](../../releases)**.
2. Прошейте архив через **Magisk**, **KernelSU** или **APatch**.
3. Перезагрузите устройство.

---

### ⚙️ Конфигурация

Файл настроек создаётся по пути:
`/sdcard/Download/MyDoH_Config.txt`

В нём можно настроить:
* Выбор провайдера (Cloudflare / Google / Comss / Свой URL).
* `USE_HTTP3=0` — выключить HTTP/3 (рекомендуется для РФ во избежание блокировок UDP 443).
* `USE_HTTP3=1` — включить HTTP/3 (QUIC).

> **Примечание:** После редактирования конфига перезапустите модуль через кнопку **Action** в менеджере модулей или перезагрузите телефон.
